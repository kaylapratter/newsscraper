# BBC News Scraper Service

A lightweight Python service that parses the BBC News RSS feed and uploads the top 5 latest articles to a Supabase database. Prepared for free automated cloud execution using GitHub Actions.

## Features
- **RSS Parsing**: Extract top 5 articles (`title`, `link`, `summary`, `published`) using `feedparser`.
- **Supabase Storage**: Automatically inserts/upserts records into the `articles` table.
- **Error Handling & Logging**: Robust exception handling and structured terminal output.
- **Automated Cloud Execution**: GitHub Actions workflow runs every 6 hours and on-demand via `workflow_dispatch`.

---

## Supabase Database Setup

Before running the scraper, create the `articles` table in your Supabase project SQL Editor:

```sql
CREATE TABLE IF NOT EXISTS articles (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title TEXT NOT NULL,
    link TEXT UNIQUE NOT NULL,
    summary TEXT,
    published TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);
```

## Local Setup & Execution

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Configure Environment (Optional)
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Default keys are pre-configured in code, but you can override them in `.env`.

### 3. Run Scraper Locally
```bash
python scraper.py
```

## Free Cloud Deployment (GitHub Actions)

1. Push this repository to GitHub.
2. Navigate to **Actions** -> **BBC News Scraper**.
3. Trigger manually using **Run workflow**, or let it execute automatically on the `0 */6 * * *` schedule (every 6 hours).
4. (Optional) Store your credentials in repository secrets under **Settings -> Secrets and variables -> Actions**:
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
